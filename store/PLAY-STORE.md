# 플레이스토어 출시 준비 (등록비 낸 뒤)

## 1. 서명 키 — 가장 중요
- 키: `D:/diet-app-keys/upload.jks`, 비밀번호: `D:/diet-app-keys/keystore.properties`
- 지인에게 준 APK도 이 키로 서명돼 있다. **스토어에 올릴 때 이 키를 "앱 서명 키"로 등록**해야(Play Console → 앱 무결성 → 앱 서명 → "다른 키 사용/키 업로드", PEPK 도구) 지인 폰의 앱이 지우지 않고 스토어 버전으로 업데이트된다.
- 키를 잃어버리면 같은 앱으로 업데이트할 수 없다. USB·클라우드 등 두 군데 이상에 백업할 것.

## 2. 올릴 파일
- `sh gw.sh :app:bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`
- 아이콘 512px: `store/icon-512.png`, 그래픽 이미지 1024×500: `store/feature-1024x500.png`
- 스크린샷: 에뮬레이터 화면(홈·기록·성과·식단) 4장 이상

## 3. 개인 개발자 계정 조건
- 정식 출시 전 비공개 테스트: 테스터 12명 이상이 14일 연속 참여
- 내부 테스트(최대 100명)는 바로 가능 — 지인용으로 쓰기 좋음

## 4. 앱 콘텐츠 신고 (Play Console)
- 개인정보처리방침 URL: 서버 배포 후 `https://<서버 주소>/privacy` (서버가 없으면 GitHub Pages 등에 같은 내용)
- 계정 삭제 URL: `https://<서버 주소>/account-deletion` (앱 안 설정 → 계정 삭제도 있음)
- 데이터 보안(Data safety):
  - 게스트: 기기 밖으로 보내는 데이터 없음
  - 구글 로그인 시 수집: 이메일·사용자 ID(계정 관리), 건강·피트니스(체중, 식단 칼로리) — 앱 기능(백업·동기화) 목적, 전송 중 암호화(HTTPS), 삭제 요청 가능, 제3자 공유 없음
  - 사진: 기기에만 저장, 수집 안 함
- 건강 앱 신고: 체중·식단 기록 앱(의료 기기 아님, 진단·치료 목적 아님)
- 대상 연령: 만 14세 이상(앱 초기 설정에서도 14세 미만은 막음)
- 광고 없음

## 5. 스토어 설명 초안
- 앱 이름: 가볍게 (임시)
- 짧은 설명(80자): 체중과 식단을 기록하고 목표까지 얼마나 왔는지 한눈에 봐요
- 자세한 설명:
  - 현재 체중, 감량한 양, 목표까지 남은 무게와 진행률
  - 주마다 평균 체중과 변화, 그 주에 먹은 식단
  - 체중 곡선(7일 평균), 목표 도달 예상일, 배지
  - 식약처 음식 영양성분 데이터 1만 7천여 개 검색, 직접 입력, 사진 첨부
  - 로그인 없이 바로 사용, 원하면 구글 계정으로 백업·기기 간 동기화
  - 음식 데이터 출처: 식품의약품안전처 전국통합식품영양성분정보(음식)표준데이터(공공데이터포털)

## 6. 출시 전 바꿀 것
- 앱 이름·패키지 이름(`io.github.adgjmptw2.diet`)은 한 번 올리면 패키지 이름은 못 바꾼다. 확정 후 올릴 것.
- `versionCode`를 올릴 때마다 1씩 증가 (`app/build.gradle.kts`)
